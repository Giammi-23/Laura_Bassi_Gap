Gap 1: Status Istituzionale e Primato Storico

Laura Bassi fu la prima donna in Europa a ottenere una posizione accademica ufficiale in fisica all'Università di Bologna. Su Wikidata, però, questo fatto non è modellato come proprietà esplicita ma è solo “implicito” nella combinazione di:

  • "occupazione" (P106) = physicist
  • "datore di lavoro" (P108) = University of Bologna

Non è utilizzata la proprietà “position held” (P39), che sottolineerebbe la carica istituzionale che le è stata assegnata tramite decreto, rafforzando il livello semantico del suo primato.

Il gap semantico è proprio questo: sebbene le fonti biografiche evidenzino il ruolo pionieristico di Laura Bassi come prima donna in Europa a ricoprire una cattedra in fisica, tale informazione non è esplicitamente modellata nel knowledge graph come relazione strutturata, ma rimane implicita nella combinazione di occupazione e affiliazione accademica.

"Occupation" vs. "Position held"

Il primato storico di Laura Bassi non è modellato come carica istituzionale (P39 — assente), ma semplicemente come occupazione. Abbiamo scoperto poi, l'esistenza di un elemento Q107609509 ("first woman to hold a position") di tipo oggetto Wikidata, non una proprietà! Questo rivela un gap non solo quantitativo (dato mancante) ma strutturale: Wikidata non dispone attualmente di un vocabolario adeguato per rappresentare primati storici di questo tipo! 

SELECT DISTINCT ?person ?personLabel ?occupation ?occupationLabel 
                ?position ?positionLabel
WHERE {
  VALUES ?person { wd:Q541652 } # La variabile ?person è tassativamente Laura Bassi
  
  OPTIONAL { wd:Q541652 wdt:P106 ?occupation }     # occupation
  OPTIONAL { wd:Q541652 wdt:P39 ?position }        # position held
  
  SERVICE wikibase:label { bd:serviceParam wikibase:language "it,en". }
}
