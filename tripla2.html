Tripla Gap 2: Premi, Riconoscimenti e Intitolazioni

Esempi pratici di query semantiche per estrarre informazioni strutturate direttamente da Wikidata.

"Award received"

Dalle fonti bibliografiche emerge che Laura Bassi ricevette diversi premi e riconoscimenti per la sua attività scientifica. Tuttavia, su Wikidata, questi non sono modellati come una classe coerente e completa di "award received" (P166). Eseguendo la query, otteniamo solo 4 risultati sotto la categoria "named after".

SELECT ?item ?type WHERE {
  {
    ?item wdt:P138 wd:Q541652 .
    BIND("named after" AS ?type)
  }
  UNION
  {
    ?item wdt:P547 wd:Q541652 .
    BIND("commemorative name" AS ?type)
  }
  UNION
  {
    ?item wdt:P166 wd:Q541652 .
    BIND("awards received" AS ?type)
  }

  SERVICE wikibase:label {
    bd:serviceParam wikibase:language "it,en".
  }
}
