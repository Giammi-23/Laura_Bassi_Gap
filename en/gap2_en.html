Gap 2: Awards, Honors, and Named Entities

From the analysis of biographical sources, it emerges that Laura Bassi has been commemorated in numerous ways, including craters, asteroids, ships, scientific institutions, and public places named in her honor. Through SPARQL queries, we wanted to verify whether these recognitions were adequately represented.

Awards, commemorations, and named entities

Biographical sources indicate that Laura Bassi received several awards and forms of recognition for her scientific achievements. However, on Wikidata these do not appear to be modeled as a coherent and comprehensive set of "award received" (P166) statements.

SELECT ?item ?type WHERE {
  {
    ?item wdt:P138 wd:Q541652 .
    BIND("named after" AS ?type)
  }
  UNION
  {
    ?item wdt:P547 wd:Q541652 .
    BIND("commemorative name" AS ?type)
  }
  UNION
  {
    ?item wdt:P166 wd:Q541652 .
    BIND("awards received" AS ?type)
  }

  SERVICE wikibase:label {
    bd:serviceParam wikibase:language "it,en".
  }
}

The many commemorations and entities named after Laura Bassi are documented in biographical sources, yet they are not modeled correctly at the semantic level within the knowledge graph. In fact, only a few appear under the "named after" category, with just four results returned.

Verification of named entities

Wikipedia's own biographical sources mention at least seven recognitions dedicated to the scientist. We therefore attempted to verify which entities were actually present in the graph: 

SELECT ?item ?itemLabel WHERE {
  ?item wdt:P138 wd:Q541652 .

  ?item rdfs:label ?itemLabel .

  FILTER(LANG(?itemLabel) = "it")

  FILTER(REGEX(LCASE(?itemLabel), "bassi"))
}

The result is disappointing. The query returns only four entities. Two of them also have labels that are not semantically meaningful: it is not intuitive for either humans or machines to understand that "Bassi" refers to a crater on Venus, nor that "Laura Bassi" refers to an icebreaker.
