Interrogazioni SPARQL

Esempi pratici di query semantiche per estrarre informazioni strutturate direttamente da Wikidata.

1. Co-allievi e docenti correlati

Questa query seleziona tutte le personalità accademiche collegate direttamente o indirettamente all'attività di Laura Bassi a Bologna.

SELECT ?collega ?collegaLabel WHERE {
  wd:Q105968 wdt:P101 ?field .       # Campo di attività di Laura Bassi
  ?collega wdt:P101 ?field ;          # Colleghi nello stesso campo
           wdt:P108 wd:Q42337 .       # Affiliati all'Università di Bologna
  SERVICE wikibase:label { bd:serviceParam wikibase:language "[AUTO_LANGUAGE],it,en". }
}
LIMIT 20
